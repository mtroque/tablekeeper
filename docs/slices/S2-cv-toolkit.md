# S2: CV toolkit

**Status:** ⬜ · **Depends on:** S0

**Goal:** the reusable, tested pipeline that turns a phone photo into a flattened, normalized board with confidence-scored cells, plus the harness that measures it. Game detection slices then add only a layout, a profile and a small classifier.

## Owns
- `packages/cv/src/pipeline/**`, `packages/cv/src/index.ts`, `packages/cv/src/games/_example/`
- `apps/web/src/workers/cv.worker.ts`, the implementation of `apps/web/src/lib/cv-client.ts` (signature fixed by S0)
- `scripts/eval-vision.ts`, `data/fixtures/_example/` (synthetic images generated by a script)

## Scope
Everything in `docs/ARCHITECTURE.md` → Computer vision: the stages, calibration profiles, the worker and `cv-client`, and `pnpm eval:cv` (including `--calibrate`). The `_example` detector reads the S1 example game's 3×3 board from synthetic images.

## Acceptance criteria
- [ ] On synthetic boards (rotated, perspective-skewed, tinted, darkened), corners are recovered within 2% of board size.
- [ ] After normalization, the same cell under warm and cool tints classifies the same.
- [ ] `_example` on synthetic fixtures: ≥ 98% cell accuracy, with an eval report.
- [ ] In the browser, detection runs without blocking the main thread and opencv loads once per page session.
- [ ] Tests confirm no leaked `Mat`s.

## Out of scope
Real game layouts and profiles; the corner UI (S1).
